# Upload to GitHub

這個資料夾整理的是適合放到 GitHub repository 的檔案。

已包含：

- Cloudflare Worker / Queue / Workflow / D1 相關程式
- 前端展示頁與樣式
- 本機與部署設定檔
- SQL schema
- 教學文件
- 產生簡報用的腳本

刻意未包含：

- `node_modules/`
- `output/`
- `.DS_Store`
- 真正的 secrets 檔案，例如 `.dev.vars`

建議你從這個資料夾上傳到 GitHub，或把裡面的內容搬到新的 repository 根目錄。
